# Métodos Instrumentales Lab

Laboratorio virtual desarrollado para la asignatura
Métodos Instrumentales de Ingeniería Ambiental.

## Objetivo

Utilizar Python, pandas y Streamlit para explorar
de manera interactiva los fundamentos de los
métodos instrumentales de análisis.

## Módulo 01 — Métodos Potenciométricos

El módulo está organizado en cinco misiones:

1. ¿Cómo puede medirse química con electricidad?
2. La ecuación de Nernst.
3. Construí tu pH-metro.
4. Calibrá el instrumento.
5. Investigá el río.

## Filosofía

Sistema ambiental → Sensor → Señal → Datos →
Información → Decisión.

## Tecnologías

- Python
- NumPy
- pandas
- Matplotlib
